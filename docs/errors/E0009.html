四、三角函数与解三角形 · E0009

2026-07-15 授课大题 · E0009

01 · 题目描述

在 △ABC\triangle ABC△ABC 中，角 A,B,CA, B, CA,B,C 所对的边分别为 a,b,ca, b, ca,b,c，且满足 sin⁡B+sin⁡C=2sin⁡Acos⁡B\sin B + \sin C = 2\sin A \cos BsinB+sinC=2sinAcosB。
(1) 证明：a2−b2=bca^2 - b^2 = bca2−b2=bc；
(2) 如图，点 DDD 在线段 ABABAB 的延长线上，且 AB=3,BD=1AB = 3, BD = 1AB=3,BD=1，当点 CCC 运动时，探究 CD−CACD - CACD−CA 是否为定值？如果为定值，求出该定值；如果不为定值，请说明理由。

02 · 当时的错解与误区
  • 第一问的正弦余弦转化极快。但在第二问中，面对动点 CCC 构成的“爪型补角模型”（∠CBA+∠CBD=π\angle CBA + \angle CBD = \pi∠CBA+∠CBD=π）时，没能直接写出余弦定理关系 cos⁡∠CBD=−cos⁡∠CBA\cos \angle CBD = -\cos \angle CBAcos∠CBD=−cos∠CBA 从而一步消参，而在复杂的边角公式中迷失了方向。
03 · 正确路径与证明流程

(1) 证明 a2−b2=bca^2 - b^2 = bca2−b2=bc

根据正弦定理，已知等式 sin⁡B+sin⁡C=2sin⁡Acos⁡B\sin B + \sin C = 2\sin A \cos BsinB+sinC=2sinAcosB 可以化为边长关系：

b+c=2acos⁡Bb + c = 2a \cos Bb+c=2acosB

代入余弦定理公式 cos⁡B=a2+c2−b22ac\cos B = \frac{a^2 + c^2 - b^2}{2ac}cosB=2aca2+c2−b2​ 得：
b+c=2a⋅(a2+c2−b22ac)⇒b+c=a2+c2−b2cb + c = 2a \cdot \left(\frac{a^2 + c^2 - b^2}{2ac}\right) \Rightarrow b + c = \frac{a^2 + c^2 - b^2}{c}b+c=2a⋅(2aca2+c2−b2​)⇒b+c=ca2+c2−b2​

两边同乘以 ccc 得：
bc+c2=a2+c2−b2⇒a2−b2=bc(证毕)bc + c^2 = a^2 + c^2 - b^2 \Rightarrow a^2 - b^2 = bc \quad (\text{证毕})bc+c2=a2+c2−b2⇒a2−b2=bc(证毕)

(2) 探究 CD−CACD - CACD−CA 是否为定值

已知在 △ABC\triangle ABC△ABC 中，c=AB=3c = AB = 3c=AB=3。
代入 (1) 中的边长结论得：

a2−b2=3b⇒CB2−AC2=3AC(1)a^2 - b^2 = 3b \Rightarrow CB^2 - AC^2 = 3AC \quad (1)a2−b2=3b⇒CB2−AC2=3AC(1)

因为点 DDD 在线段 ABABAB 的延长线上，且 BD=1BD = 1BD=1，所以有 AD=AB+BD=4AD = AB + BD = 4AD=AB+BD=4。

在 △ABC\triangle ABC△ABC 中，根据余弦定理有：

cos⁡∠CBA=CB2+AB2−AC22⋅CB⋅AB=CB2+9−AC26CB\cos \angle CBA = \frac{CB^2 + AB^2 - AC^2}{2 \cdot CB \cdot AB} = \frac{CB^2 + 9 - AC^2}{6CB}cos∠CBA=2⋅CB⋅ABCB2+AB2−AC2​=6CBCB2+9−AC2​

将 (1) 式 CB2−AC2=3ACCB^2 - AC^2 = 3ACCB2−AC2=3AC 代入上式化简得：
cos⁡∠CBA=3AC+96CB=AC+32CB(2)\cos \angle CBA = \frac{3AC + 9}{6CB} = \frac{AC + 3}{2CB} \quad (2)cos∠CBA=6CB3AC+9​=2CBAC+3​(2)

在 △CBD\triangle CBD△CBD 中，根据余弦定理（其中 BD=1BD = 1BD=1）：

cos⁡∠CBD=BD2+CB2−CD22⋅BD⋅CB=1+CB2−CD22CB(3)\cos \angle CBD = \frac{BD^2 + CB^2 - CD^2}{2 \cdot BD \cdot CB} = \frac{1 + CB^2 - CD^2}{2CB} \quad (3)cos∠CBD=2⋅BD⋅CBBD2+CB2−CD2​=2CB1+CB2−CD2​(3)

因为点 A,B,DA, B, DA,B,D 三点共线，所以 ∠CBA+∠CBD=π\angle CBA + \angle CBD = \pi∠CBA+∠CBD=π，根据诱导公式有：
cos⁡∠CBD=−cos⁡∠CBA\cos \angle CBD = -\cos \angle CBAcos∠CBD=−cos∠CBA

将 (2) 和 (3) 代入上式：
1+CB2−CD22CB=−AC+32CB⇒1+CB2−CD2=−AC−3⇒CB2−CD2+AC+4=0(4)\frac{1 + CB^2 - CD^2}{2CB} = -\frac{AC + 3}{2CB} \Rightarrow 1 + CB^2 - CD^2 = -AC - 3 \Rightarrow CB^2 - CD^2 + AC + 4 = 0 \quad (4)2CB1+CB2−CD2​=−2CBAC+3​⇒1+CB2−CD2=−AC−3⇒CB2−CD2+AC+4=0(4)

再将 (1) 式 CB2=AC2+3ACCB^2 = AC^2 + 3ACCB2=AC2+3AC 代入 (4) 式消去 CB2CB^2CB2 得：
(AC2+3AC)−CD2+AC+4=0⇒AC2+4AC−CD2+4=0(AC^2 + 3AC) - CD^2 + AC + 4 = 0 \Rightarrow AC^2 + 4AC - CD^2 + 4 = 0(AC2+3AC)−CD2+AC+4=0⇒AC2+4AC−CD2+4=0

配方得：
(AC+2)2−CD2=0⇒(AC+2+CD)(AC+2−CD)=0(AC + 2)^2 - CD^2 = 0 \Rightarrow (AC + 2 + CD)(AC + 2 - CD) = 0(AC+2)2−CD2=0⇒(AC+2+CD)(AC+2−CD)=0

因为线段长度满足 AC>0,CD>0⇒AC+CD+2>0AC > 0, CD > 0 \Rightarrow AC + CD + 2 > 0AC>0,CD>0⇒AC+CD+2>0。
所以只能有：
AC+2−CD=0⇒CD−AC=2AC + 2 - CD = 0 \Rightarrow CD - AC = 2AC+2−CD=0⇒CD−AC=2

故 CD−CACD - CACD−CA 是定值，该定值为 222。
