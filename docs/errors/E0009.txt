1f:T771,### (1) 证明 $a^2 - b^2 = bc$
根据正弦定理，已知等式 $\sin B + \sin C = 2\sin A \cos B$ 可以化为边长关系：
$$b + c = 2a \cos B$$
代入余弦定理公式 $\cos B = \frac{a^2 + c^2 - b^2}{2ac}$ 得：
$$b + c = 2a \cdot \left(\frac{a^2 + c^2 - b^2}{2ac}\right) \Rightarrow b + c = \frac{a^2 + c^2 - b^2}{c}$$
两边同乘以 $c$ 得：
$$bc + c^2 = a^2 + c^2 - b^2 \Rightarrow a^2 - b^2 = bc \quad (\text{证毕})$$

---

### (2) 探究 $CD - CA$ 是否为定值
已知在 $\triangle ABC$ 中，$c = AB = 3$。
代入 (1) 中的边长结论得：
$$a^2 - b^2 = 3b \Rightarrow CB^2 - AC^2 = 3AC \quad (1)$$
因为点 $D$ 在线段 $AB$ 的延长线上，且 $BD = 1$，所以有 $AD = AB + BD = 4$。

在 $\triangle ABC$ 中，根据余弦定理有：
$$\cos \angle CBA = \frac{CB^2 + AB^2 - AC^2}{2 \cdot CB \cdot AB} = \frac{CB^2 + 9 - AC^2}{6CB}$$
将 (1) 式 $CB^2 - AC^2 = 3AC$ 代入上式化简得：
$$\cos \angle CBA = \frac{3AC + 9}{6CB} = \frac{AC + 3}{2CB} \quad (2)$$

在 $\triangle CBD$ 中，根据余弦定理（其中 $BD = 1$）：
$$\cos \angle CBD = \frac{BD^2 + CB^2 - CD^2}{2 \cdot BD \cdot CB} = \frac{1 + CB^2 - CD^2}{2CB} \quad (3)$$
因为点 $A, B, D$ 三点共线，所以 $\angle CBA + \angle CBD = \pi$，根据诱导公式有：
$$\cos \angle CBD = -\cos \angle CBA$$
将 (2) 和 (3) 代入上式：
$$\frac{1 + CB^2 - CD^2}{2CB} = -\frac{AC + 3}{2CB} \Rightarrow 1 + CB^2 - CD^2 = -AC - 3 \Rightarrow CB^2 - CD^2 + AC + 4 = 0 \quad (4)$$
再将 (1) 式 $CB^2 = AC^2 + 3AC$ 代入 (4) 式消去 $CB^2$ 得：
$$(AC^2 + 3AC) - CD^2 + AC + 4 = 0 \Rightarrow AC^2 + 4AC - CD^2 + 4 = 0$$
配方得：
$$(AC + 2)^2 - CD^2 = 0 \Rightarrow (AC + 2 + CD)(AC + 2 - CD) = 0$$
因为线段长度满足 $AC > 0, CD > 0 \Rightarrow AC + CD + 2 > 0$。
所以只能有：
$$AC + 2 - CD = 0 \Rightarrow CD - AC = 2$$
故 $CD - CA$ 是定值，该定值为 $2$。
