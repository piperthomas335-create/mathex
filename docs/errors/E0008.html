03 · 正确路径与证明流程

(1) 验证 y=xy=xy=x 是否为 y=sin⁡xy=\sin xy=sinx 的导控函数

令 f(x)=x⇒f′(x)=1f(x) = x \Rightarrow f'(x) = 1f(x)=x⇒f′(x)=1。
令 g(x)=sin⁡x⇒g′(x)=cos⁡xg(x) = \sin x \Rightarrow g'(x) = \cos xg(x)=sinx⇒g′(x)=cosx。
因为对任意 x∈Rx \in \mathbb{R}x∈R，恒有 −1≤cos⁡x≤1-1 \le \cos x \le 1−1≤cosx≤1，所以有：

f′(x)=1≥cos⁡x=g′(x)f'(x) = 1 \ge \cos x = g'(x)f′(x)=1≥cosx=g′(x)

故函数 y=xy=xy=x 是函数 y=sin⁡xy=\sin xy=sinx 的“导控函数”。

(3) 证明 g(x)−f(x)=cg(x) - f(x) = cg(x)−f(x)=c 恒成立

因为 f(x)f(x)f(x) 与 g(x)g(x)g(x) 均为定义在 R\mathbb{R}R 上的偶函数，即对任意 x∈Rx \in \mathbb{R}x∈R：

f(x)=f(−x),g(x)=g(−x)f(x) = f(-x), \quad g(x) = g(-x)f(x)=f(−x),g(x)=g(−x)

两边求导可得其导数的性质：
f′(x)=−f′(−x),g′(x)=−g′(−x)f'(x) = -f'(-x), \quad g'(x) = -g'(-x)f′(x)=−f′(−x),g′(x)=−g′(−x)

即偶函数的导函数均为奇函数。

因为 y=g(x)y=g(x)y=g(x) 是 y=f(x)y=f(x)y=f(x) 的“导控函数”，所以对任意 x∈Rx \in \mathbb{R}x∈R，有：

g′(x)≥f′(x)(A)g'(x) \ge f'(x) \quad (A)g′(x)≥f′(x)(A)

用 −x-x−x 替换上式中的 xxx，得：
g′(−x)≥f′(−x)g'(-x) \ge f'(-x)g′(−x)≥f′(−x)

代入奇函数关系 g′(−x)=−g′(x)g'(-x) = -g'(x)g′(−x)=−g′(x) 和 f′(−x)=−f′(x)f'(-x) = -f'(x)f′(−x)=−f′(x) 得：
−g′(x)≥−f′(x)⇒g′(x)≤f′(x)(B)-g'(x) \ge -f'(x) \Rightarrow g'(x) \le f'(x) \quad (B)−g′(x)≥−f′(x)⇒g′(x)≤f′(x)(B)

结合不等式 (A) 和 (B)，对于任意 x∈Rx \in \mathbb{R}x∈R，均有：
g′(x)=f′(x)g'(x) = f'(x)g′(x)=f′(x)

所以：
(g(x)−f(x))′=g′(x)−f′(x)=0(g(x) - f(x))' = g'(x) - f'(x) = 0(g(x)−f(x))′=g′(x)−f′(x)=0
